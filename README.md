# SmartTrip AI 🌍✈️

SmartTrip AI is an AI-powered travel planner that generates personalized travel itineraries based on destination, budget, trip duration, and interests.

## Features

- AI-generated travel itineraries
- Destination images
- Live weather information
- Interactive map
- Google Maps location links
- Suggested transport options
- Save trips
- User authentication
- Download itinerary as PDF

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- Leaflet Maps

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication
- Groq AI API
